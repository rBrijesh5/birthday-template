# 🎂 Birthday Surprise Website

A simple interactive birthday website built with HTML, CSS and JavaScript.

## Features

- 🎉 Birthday message sequence
- 🎵 Background music player
- ❤️ Floating hearts animation
- 🎈 Balloons effect
- 🎊 Confetti celebration
- 📱 Mobile responsive
- 🎨 Clean modern design

---

## Customization

Open `script.js`

```javascript
const config = {
    birthdayPerson: "BOB",
    sender: "BRIJESH"
};
```

### Change Birthday Person

```javascript
birthdayPerson: "John"
```

### Change Sender Name

```javascript
sender: "Alex"
```

### Change Music

Replace:

```html
<audio id="music" src="happy-birthday.mp3"></audio>
```

with your own music file.
